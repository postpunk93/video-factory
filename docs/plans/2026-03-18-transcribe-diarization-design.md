# Дизайн: transcribe.py — расшифровка с диаризацией

**Дата:** 2026-03-18
**Статус:** Утверждён

## Цель

Скрипт для транскрибации созвонов с определением спикеров. Входит в этап 2 пайплайна (транскрибация интервью). Записи — одна аудиодорожка из Zoom/Google Meet, обычно 2 спикера.

## Подход

**whisperX** — обёртка над faster-whisper + pyannote-audio:
1. Транскрибация (faster-whisper, модель large-v3)
2. Выравнивание таймкодов по словам
3. Диаризация (pyannote — определение спикеров)
4. Присвоение слов спикерам

Альтернативы рассмотрены и отклонены:
- faster-whisper + pyannote вручную — повторяет то, что whisperX уже делает
- NVIDIA NeMo — тяжёлый фреймворк, сложнее интеграция

## Архитектура

Отдельный скрипт `_scripts/transcribe.py`. Не расширяем cut_pauses.py — разные задачи.

### Пайплайн

```
Видео/аудио → [1. whisperX: транскрибация + выравнивание]
             → [2. pyannote: диаризация]
             → [3. Совмещение + вывод в TXT и JSON]
```

### CLI

```bash
python _scripts/transcribe.py projects/tulips/01_raw/call1.mp4 --speakers 2
python _scripts/transcribe.py projects/tulips/01_raw/ --speakers 2 --model large-v3
```

**Аргументы:**
- `input` — файл или папка
- `--speakers` — ожидаемое число спикеров (default: 2)
- `--model` — модель Whisper (default: large-v3)
- `--output` — папка для результатов (default: рядом с исходником)
- `--hf-token` — HuggingFace токен (или переменная `HF_TOKEN`)

## Выходные форматы

### TXT (для человека)

```
Расшифровка: call1.mp4
Дата: 2026-03-18
Спикеры: 2
Длительность: 45:12

──────────────────────────────────

[00:00:03 → 00:00:15] Спикер 1:
Давай расскажи как ты вообще попал в этот бизнес с тюльпанами

[00:00:16 → 00:00:45] Спикер 2:
Ну смотри я начал в 2018 году когда ещё работал в найме и параллельно
начал выращивать в теплице у себя на участке

──────────────────────────────────
```

Смежные реплики одного спикера склеиваются в один блок. Текст без пунктуации — чтобы можно было искать в оригинале.

### JSON (для автоматизации)

```json
{
  "source": "call1.mp4",
  "duration": 2712.5,
  "speakers_count": 2,
  "segments": [
    {
      "speaker": "Спикер 1",
      "start": 3.12,
      "end": 15.40,
      "text": "давай расскажи как ты вообще попал в этот бизнес с тюльпанами",
      "words": [
        {"word": "давай", "start": 3.12, "end": 3.45},
        {"word": "расскажи", "start": 3.50, "end": 3.98}
      ]
    }
  ]
}
```

Word-level таймкоды в JSON — пригодится для автоматической нарезки реплик героя (этап 6 pipeline).

**Имена файлов:** `call1.transcript.txt`, `call1.transcript.json`

## Обработка ошибок

- **Плохой звук** — не чистим, это отдельная задача (этап 11 pipeline)
- **Перебивания** — оставляем как есть, два блока с пересекающимися таймкодами
- **Число спикеров** — если pyannote нашёл больше чем `--speakers`, предупреждение, не падаем
- **Длинные записи (1-2 часа)** — whisperX работает батчами, прогресс через tqdm
- **HF токен** — понятное сообщение с инструкцией если не указан

## Зависимости

- whisperx
- pyannote.audio (скачивается через HuggingFace, нужен токен + accept conditions)
- faster-whisper (подтягивается через whisperx)
- tqdm
- ffmpeg в PATH
