## Детали по этапам

### 1. Сжатие записей
Записи созвонов иногда весят десятки ГБ. Нужен ffmpeg скрипт для сжатия в h265 с адекватным битрейтом.

### 2. Транскрибация созвонов
faster-whisper с word-level timestamps. Основа уже есть в cut_pauses.py (флаг --save-transcript). Нужно оформить как отдельный инструмент.

### 3. Картинки/таблицы → markdown
Claude Code читает PNG и распознаёт таблицы. Проверено на двух таблицах (kogtetochki-5.png, kogtetochki-6.png) — работает точно. Оформить в скилл /image-to-md.

### 4. Написание сценария
Скилл youtube-script на команде Рюмина. Известные проблемы: вкладывает реплики героя в слова Славы, сложные формулировки, выдумывает факты. Правило: Слава говорит про индустрию, история героя — только словами героя.

### 5. Нарезка дорожки Славы
Слава присылает начитку одним видеофайлом. Нужно убрать паузы, оговорки, комментарии. **Решено** — cut_pauses.py.

### 6. Нарезка реплик героя
Сценарий в Google Docs содержит три колонки: речь Славы | реплики героя | файл + таймкоды. Экспорт в CSV → парсинг третьей колонки (формат: `тюльпаны 2, 00:09:24 – 00:09:53`) → ffmpeg cut.

### 7. Сборка проекта Premiere Pro
Генерация FCP 7 XML с таймлайном. Клипы на дорожках по ролям (Слава / герой). Монтажёр получает готовый черновой монтаж.

### 8. Поиск иллюстраций
Источники: Freepik, Pexels, YouTube (Creative Commons). Claude помогает с запросами, но юмор/мемы подбираются вручную. Можно автоматизировать базовый поиск через API стоков + LLM.

### 9. Таблицы для видео
Таблицы из статьи часто не подходят для видео — монтажёр делает отдельные. Claude помогает с визуализацией. Оформить в скилл/шаблон.

### 10. Шаблоны анимации
Есть шаблоны (плашки, титры, таблички) в Premiere Pro, но при переносе между проектами анимация слетает. Решение — After Effects scripting. Требует отдельного исследования.

### 11. Улучшение звука
Опциональный шаг перед субтитрами. Если качество созвона плохое, Whisper транскрибирует криво. Решение: ffmpeg-фильтры (noise reduction, normalization) или Descript/Glinq до транскрибации.

### 12. Субтитры героя
Экспорт аудио из Premiere → Whisper → SRT. Важно: субтитры только для героя, субтитры Славы удаляются.

### 13. Финальная проверка и выгрузка
