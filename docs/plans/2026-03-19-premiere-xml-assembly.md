# Черновая сборка в Premiere Pro через FCP XML

## Что сделали

### 1. Обсуждение подхода
- Задача: собрать черновой проект для монтажёра (Настя, Premiere Pro)
- Исходники: начитка Славы (.mov) + 3 интервью с героем (.mp4)
- Сценарий: script.csv с таймкодами реплик Славы (колонка 2) и героя (колонка 4)
- Решение: генерировать FCP XML вместо нарезки на файлы — монтажёр импортирует XML, видит готовый таймлайн

### 2. Парсинг таймкодов героя
Таймкоды героя в script.csv были в разнобой форматах:
- `тюльпаны_2.srt, 00:42:19 – 00:42:32`
- `тюльпаны 2, 00:23:04 – 00:23:28`
- `0:33:41 тюльпаны 2,` (без конца)
- `00:32:14 → 00:32:47 тюльпаны_2.srt.`
- VK-ссылки (пропускаем)

Всё замаплено на mp4:
- тюльпаны / тюльпаны.srt → Тюльпаны.mp4
- тюльпаны_2 / тюльпаны 2 → Тюльпаны 2.mp4
- тюльпаны 4 / тюльпаны4 → Тюльпаны4.mp4

### 3. Генерация FCP XML — первая попытка
Проблемы:
- **Клипы сливались в один сегмент** — не хватало обязательных элементов в XML
- **Цвета красили файлы в бине, а не клипы на таймлайне** — `<labels>` в FCP XML так работает
- **Абсолютные пути** — не работало при передаче другому человеку

### 4. Исследование спецификации FCP XML
Источники:
- Apple FCP XML Elements Spec (developer.apple.com)
- Рабочие примеры XML (github.com/ccnmtl/xmeml)
- Adobe Community — labels не работают для timeline в Premiere

Обнаружили, что в clipitem **обязательны** элементы, которых у нас не было:
- `<duration>` — длительность исходного файла
- `<link>` — связь между видео и аудио клипами
- `<masterclipid>` — идентификация мастер-клипа
- `<sourcetrack>` — тип медиа (video/audio)
- `<enabled>` — включён ли клип

В `<sequence>` отсутствовал обязательный `<duration>`.

### 5. Исправленный XML — работает
После добавления всех обязательных элементов:
- Клипы отображаются отдельными сегментами на таймлайне
- 1-кадровый зазор между клипами
- Два варианта: относительные пути (для передачи) и абсолютные (для локальной работы)
- Цвета: монтажёр красит руками по трекам (4 клика)

### 6. Точные таймкоды (v2)
- Создали words_precise.txt — пословный таймкод с точностью до сотых секунды
- 4 параллельных агента пересопоставили 74 реплики Славы
- 8 раздутых end-таймкодов скорректированы автоматически
- Формат в CSV: `MM:SS.ss -> MM:SS.ss`

## Текущие проблемы

### Точность начал отрезков
- WhisperX даёт пословные таймкоды с погрешностью ~0.1-0.3с
- Агенты не слышат аудио, берут цифры из транскрипта
- При фальстартах (Слава начинал и бросал) агенты иногда выбирают начало первого захода вместо чистового
- Нужен другой подход: детекция тишины, хэндлы, или ручная доводка

## Выводы для скилла
- FCP XML xmeml v5 — рабочий формат для Premiere Pro
- Обязательно: duration, link, masterclipid, sourcetrack, enabled в каждом clipitem
- Labels в XML не красят клипы на таймлайне — только в бине
- Секвенция: подстраивать под основной визуал (интервью 1080p 23.976fps)
- Относительные пути (просто имя файла) — для переносимости
- Zip-архив с XML + исходниками — удобный формат передачи монтажёру
