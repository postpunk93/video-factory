# Рефакторинг скилла youtube-script

**Дата:** 2026-03-27
**Статус:** утверждён

## Цель

Перенести скилл написания сценариев из web-Claude в Claude Code (factory), адаптировать под проект, исправить структурные ошибки, сократить размер.

## Контекст

Текущий скилл (`youtube-skill.md` в корне) — ~1000 строк, написан для web-Claude (Projects). Проблемы:
- Сломанный frontmatter (два блока, парсер берёт первый — бесполезный)
- Description описывает процесс вместо триггеров (нарушение CSO)
- Хардкод `/mnt/project/` и `view` tool — не работает в Claude Code
- ~5000 слов (рекомендация <500), правила дублируются 3-5 раз
- Все примеры привязаны к одному домену (кофе)
- Выходной формат — markdown в чат, а не CSV для пайплайна
- Шортсы смешаны с основным сценарием

## Решение

### 1. Структура файлов

```
.claude/commands/
  youtube-script.md          # Основной скилл (~300-400 слов)
  youtube-script-examples.md # Развёрнутые примеры хорошо/плохо
docs/notes/
  youtube-shorts-skill-idea.md  # Заготовка для будущего скилла шортсов
```

### 2. Frontmatter

```yaml
---
name: youtube-script
description: "Создание сценария видео для YouTube. Использование: /youtube-script <project_dir> (например: /youtube-script projects/tulips). Требует: raw/article.md + transcripts/*.transcript.txt в папке проекта."
---
```

### 3. Шаги скилла

**Шаг 0: Чтение материалов**
- Читает `<project_dir>/raw/article.md` и `<project_dir>/transcripts/*.transcript.txt`
- Если аргумент не передан — спрашивает проект

**Шаг 1: Таблица цифр**
- Все цифры из материалов в таблицу, показать пользователю, дождаться подтверждения
- Правила: не придумывать, не округлять, помечать [РАСЧЁТ] и [НУЖНО УТОЧНИТЬ]

**Шаг 2: Фокус исследования**
- Денежный вопрос, цепочка создания ценности, место героя, открывающие вопросы, трёхактная структура
- Показать пользователю, дождаться подтверждения

**Шаг 3: Написание сценария**
- Правила цитат: только из расшифровок, без редактирования, приоритет самодостаточным
- Правила распределения: 70% герой / 30% автор
- Правила доступности: мостики, введение терминов, без диалоговых паттернов

**Шаг 4: Сохранение**
- CSV 4 колонки: `Слава, Таймкоды, Герой, Таймкоды`
- Скилл заполняет только 1-ю и 3-ю колонки (реплики), таймкоды — пустые
- Сохраняет в `<project_dir>/script/script_draft.csv`

**Шаг 5: Финальная проверка**
- Один компактный чеклист вместо 7 секций

### 4. Что выносим в youtube-script-examples.md

- Таблица цифр про кофе
- Примеры ошибок с цифрами (округление, опт/розница, цепочки)
- Примеры самодостаточных vs несамодостаточных цитат
- Примеры подводок
- Антипаттерны распределения контента
- Примеры смысловых мостиков
- Примеры введения информации (термины, места, виды, процессы)

### 5. Что выносим в youtube-shorts-skill-idea.md

Заготовка для будущего отдельного скилла `/youtube-shorts`:
- 4 критерия эпизода (интрига, структура, завершённость, самодостаточность)
- Правила и типы интриги
- Что НЕ является эпизодом
- Паттерн конструирования (хук → наращивание → панч)
- Формула интриги

### 6. Правила — без изменений

Содержательно правила остаются прежними, только переупаковка:
- Таблица цифр перед написанием
- Золотое правило цифр (не придумывать, не округлять)
- Цитаты только из расшифровок, без редактирования
- Приоритет самодостаточных цитат
- Распределение 70/30
- Денежный вопрос + цепочка создания ценности
- Трёхактная структура
- Правила доступности (мостики, термины, без диалоговых паттернов)

### 7. Что НЕ трогаем

- Остальные скрипты пайплайна (`_scripts/`)
- Существующий скилл `match-timecodes`
- Структуру проектных папок
- `script/script.csv` (рабочие данные) — скилл пишет в `script_draft.csv`

## Workflow в контексте пайплайна

```
1. Загрузить записи интервью и статью в проект
2. transcribe.py → расшифровки в transcripts/
3. /youtube-script <project> → script/script_draft.csv (ЭТОТ СКИЛЛ)
4. Доработка сценария (в чате + Google Sheets)
5. Слава записывает реплики по сценарию
6. Загрузить запись Славы в raw/voiceover/
7. match_timecodes.py search → candidates.json
8. /match-timecodes → verified.json
9. match_timecodes.py snap → script.csv
10. build_xml.py → assembly/*.xml → Premiere Pro
```
