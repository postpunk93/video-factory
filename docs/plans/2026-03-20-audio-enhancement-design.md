# Улучшение качества звука Zoom-записей

**Дата:** 2026-03-20
**Статус:** эксперимент

## Проблема

Записи героя из Zoom имеют плоский металлический звук, который контрастирует со студийной начиткой Славы. При сборке видео переходы между дорожками режут ухо.

**Цель:** сблизить звучание Zoom-записей со студийным голосом Славы.

## Выбранный инструмент: Resemble Enhance

- **Репо:** https://github.com/resemble-ai/resemble-enhance
- **Лицензия:** MIT
- **Что делает:** двухступенчатый пайплайн — denoiser (убирает шум) + enhancer (улучшает тембр, расширяет частотный диапазон до 44.1kHz)
- **VRAM:** ~5-6 GB (RTX 4060 8GB — хватает)
- **Python:** `pip install resemble-enhance`

### Почему Resemble Enhance

Единственный open-source инструмент, который не просто чистит шум, а именно *улучшает* звук — добавляет теплоту и полноту, что нужно для сближения Zoom с студийным звучанием.

### Рассмотренные альтернативы

| Инструмент | Denoise | Enhance | Вердикт |
|------------|---------|---------|---------|
| ClearerVoice-Studio | Отличный | Нет | Только чистка, не улучшает тембр |
| DeepFilterNet v3 | Хороший | Нет | Лёгкий denoiser, но этого мало |
| VoiceFixer | Да | Частично | Заброшен (2021) |
| NVIDIA Broadcast | Да | Нет | Нет Python API |

**Запасной план:** если denoise в Resemble Enhance окажется слабым — двухступенчатый пайплайн ClearerVoice (denoise) → Resemble Enhance (enhance only).

## Эксперимент

### Шаги

1. Установить `resemble-enhance`
2. Извлечь аудио из одного Zoom-файла (фрагмент из `Тюльпаны.mp4`)
3. Прогнать в трёх режимах:
   - только denoise
   - только enhance
   - denoise + enhance
4. Сравнить на слух с оригиналом и голосом Славы

### Соглашения

- Обработанные файлы — рядом с оригиналом, суффикс `_enhanced`
- Оригиналы не перезаписываются

### Критерий успеха

Звук Zoom-записи заметно ближе к звучанию Славы, без артефактов.

## Дальнейшие шаги (после эксперимента)

- Если результат устраивает — написать скрипт `enhance_audio.py` для пайплайна
- Обновить `build_xml.py` чтобы подхватывал `_enhanced` версии
- Рассмотреть автоматическое определение "какие файлы — Zoom" по метаданным
