# Реструктуризация папок проекта

## Проблема

Текущая структура (`01_raw/`, `02_cuts/`, ...) линейна и не масштабируется:
- Транскрипты падают в `01_raw/` рядом с видео
- Нет места для новых типов артефактов (аудио, сценарий, субтитры)
- Нумерация ломается при добавлении этапов

## Решение

Папки по типу контента вместо нумерации по этапам.

```
projects/2025-01-когтеточки/
├── raw/
│   ├── interviews/                    ← записи созвонов (1+)
│   ├── voiceover/                     ← начитка Славы (1 файл)
│   └── article.md                     ← статья-основа
│
├── transcripts/                       ← transcribe.py
│   ├── video1343572807.transcript.txt
│   └── video1343572807.transcript.json
│
├── cuts/                              ← все нарезки (cut_pauses, реплики героя)
│   ├── slava_voiceover_clean.mp4      ← очищенная начитка
│   ├── video1343572807_00-09-24.mp4   ← реплика героя
│   └── video1343572807_00-15-10.mp4   ← ещё реплика
│
├── audio/                             ← извлечённый звук (будущее)
│
├── script/                            ← сценарий (будущее)
│
├── subtitles/                         ← SRT-файлы (будущее)
│
├── assembly/                          ← FCP XML, проект (будущее)
│
├── publish/                           ← финал + мета
│
└── project.md                         ← статус, заметки
```

## Принципы

- **Скрипты не знают про структуру проекта** — принимают вход + `--output`, кладут результат куда скажут
- **Оркестрация — на агенте/скилле**, который знает структуру и вызывает скрипты с правильными путями
- **Плоские выходы** — имя исходника в имени файла, без подпапок на каждый файл
- **`raw/` разделена по ролям** — `interviews/` и `voiceover/`, т.к. созвонов бывает несколько

## Изменения

1. `task.md` → `docs/archive/task-cut-pauses.md`
2. `CLAUDE.md` — обновить структуру проекта
3. `projects/test/` — мигрировать на новую структуру
4. Скрипты не меняются (уже поддерживают `--output`)
