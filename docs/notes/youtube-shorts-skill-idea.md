## Правила создания эпизодов для шортсов

### ГЛАВНЫЙ ПРИНЦИП

**Эпизод = кусок сценария, который можно вырезать и показать как отдельный шортс/рилс.**

НЕ весь сценарий делится на эпизоды. Это нормально. Переходы, связки, контекст — это части длинного видео, НЕ эпизоды.

### КРИТЕРИИ ЭПИЗОДА (все 4 обязательны)

Помечай как **ЭПИЗОД** только если выполнены **ВСЕ 4 пункта:**

#### 1. Интрига в первые 1-3 секунды

**Главное правило интриги:** Должна быть понятна ШИРОКОМУ зрителю БЕЗ знания индустрии/процесса производства.

**Интрига использует только то, что УЖЕ есть в повседневной жизни зрителя:**
- ✅ Знакомые бренды (Озон, Яндекс)
- ✅ Привычные понятия (продавец, цена, чашка кофе)
- ✅ География (Эфиопия = бедная страна)
- ✅ Конечный продукт (чашка кофе, диван, поездка)

**Интрига НЕ использует:**
- ❌ Термины из индустрии (обжарщик, фермер, контейнер, зелёное зерно)
- ❌ Процессы производства (обжарка, ужарка, фасовка)
- ❌ Участников цепочки (трейдер, импортёр, станция обработки)

**ТИПЫ ИНТРИГИ:**

**А) Провокационное утверждение + конфликт:**

✅ **ХОРОШО:** "Озон забирает себе больше, чем остаётся продавцу"
- Озон = знают все
- Продавец = понятно
- "Больше чем" = конфликт

✅ **ХОРОШО:** "Кофе в вашей чашке стоит 11 рублей. Но платите вы 300"
- Чашка кофе = из жизни зрителя
- 11 vs 300 = контраст, конфликт

✅ **ХОРОШО:** "Фермер в Эфиопии зарабатывает всего доллар в день, и это в лучшем случае"
- Эфиопия = география, понятно что бедная страна
- "Всего" = оценка
- "В лучшем случае" = драма

❌ **ПЛОХО:** "Фермер получает доллар в день"
- Какой фермер? (непонятно)
- Нет географии
- Нет оценки/конфликта

❌ **ПЛОХО:** "Обжарщик зарабатывает рубль с чашки"
- Что такое обжарщик? (термин из индустрии)

**Б) Вопрос + понятный контекст:**

✅ **ХОРОШО:** "Сколько зарабатывают на вашей поездке в такси?"
- Поездка в такси = из жизни зрителя
- Понятен контекст

❌ **ПЛОХО:** "Сколько получает фермер за вашу чашку кофе?"
- Зритель не знает что в производстве кофе есть фермер
- Требует знания процесса

**В) Контраст ожидания vs реальность:**

✅ **ХОРОШО:** "Кофейня берёт 300 рублей за чашку. На сам кофе уходит только 11"
- Все термины из жизни зрителя

**ФОРМУЛА хорошей интриги:**
```
[Понятие из жизни зрителя] + [Шокирующий факт/цифра] + [Конфликт/оценка]
```

#### 2. Структура: Вопрос → Наращивание → Панч

**Эпизод должен иметь развитие:**

```
[ИНТРИГА - 1 фраза]
[НАРАЩИВАНИЕ - расчёт, факты, шаг за шагом]
[ПАНЧ - цитата героя или вывод]
```

✅ **Пример:**
```
Озон забирает себе больше, чем остаётся продавцу. [ИНТРИГА]

Сначала комиссия 14%. Дальше эквайринг 6%.
Потом логистика — 382 рубля. И последняя миля 4%.
Давайте посчитаем. Средний чек 1450 рублей.
Из них Озону нужно заплатить 739 рублей. [НАРАЩИВАНИЕ]

[Цитата: "Озон забирает больше чем остаётся продавцу"] [ПАНЧ]
```

#### 3. Завершённость (есть ответ, не обрывается)

Эпизод должен заканчиваться конкретным выводом, не висеть в воздухе.

✅ **ХОРОШО:**
```
Итого Озону — 739 рублей. Это больше половины продажной цены.
```

❌ **ПЛОХО (обрывается на вопросе):**
```
Но на рынке есть те, кто продаёт дешевле. Как они это делают?
```
(нет ответа - это переход к следующему разделу, НЕ эпизод)

#### 4. Самодостаточность (понятно О ЧЁМ речь)

Человек, который НЕ видел предыдущие части, должен понять о чём речь.

**ТЕСТ:** Закрой весь сценарий выше. Прочитай только этот кусок. Понятно?

✅ **ХОРОШО:**
```
Кофе в вашей чашке стоит 11 рублей. Но платите вы 300.
Откуда кофейня берёт эти зёрна?...
```
(понятен контекст без предыдущего)

❌ **ПЛОХО:**
```
Может быть, обжарщик мог бы снизить цену?
[цитата]
Цены устанавливаются конкуренцией...
```
(кто такой обжарщик? о чём речь? требует контекста)

### ЧТО НЕ ЯВЛЯЕТСЯ ЭПИЗОДОМ

**НЕ помечай как ЭПИЗОД:**

1. **Переходы между разделами**
   ```
   ❌ "А теперь перейдём к следующему участнику цепочки..."
   ❌ "Вернёмся к обжарщику..."
   ❌ "Но это ещё не всё..."
   ```

2. **Ввод терминов без интриги**
   ```
   ❌ "Кофейня покупает обжаренный кофе. Его делают обжарщики."
   ```

3. **Середина объяснения**
   ```
   ❌ "При этом нужно учитывать..."
   ❌ "Дальше происходит следующее..."
   ```

4. **Вопросы без ответа (обрывы)**
   ```
   ❌ "Но как же тогда они зарабатывают?"
   ```

5. **Использование терминов индустрии в начале**
   ```
   ❌ "Трейдер покупает кофе у станции обработки..."
   ❌ "Дестонер очищает зерно от камней..."
   ❌ "При ужарке теряется 20%..."
   ```

### Пометка эпизодов в сценарии

При написании сценария помечай эпизоды так:

```
ЭПИЗОД: [Краткое название]

| Автор | Герой | Файл |
|-------|-------|------|
| [Интрига] | | |
| [Наращивание...] | | |
| | [Панч - цитата] | файл, тайминг |
```

### ⛔ Чеклист: проверь перед разметкой эпизодов:

- [ ] Интрига понятна широкому зрителю БЕЗ знания индустрии
- [ ] Интрига использует только понятия из жизни зрителя
- [ ] Эпизод имеет структуру: Вопрос → Наращивание → Панч
- [ ] Эпизод завершён (не обрывается на вопросе)
- [ ] Эпизод самодостаточен (понятен без контекста)
- [ ] Понял что НЕ является эпизодом (переходы, вводы терминов, обрывы)
