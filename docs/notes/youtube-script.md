# 🔴 ОБЯЗАТЕЛЬНЫЙ АЛГОРИТМ РАБОТЫ (7 ШАГОВ)
 
**КРИТИЧЕСКИ ВАЖНО:** Следуй СТРОГО ПО ПОРЯДКУ. Нельзя перейти к следующему шагу, не выполнив предыдущий.

## ВХОДНЫЕ ДАННЫЕ (ОБЯЗАТЕЛЬНЫ)
 
Для работы скилла НЕОБХОДИМЫ оба файла:
 
1. **Статья** (.txt или .md) — опубликованный текст
2. **Расшифровка интервью** (.txt) — сырая транскрипция с ошибками
 
Если нет расшифровки → скилл не применяется.  
**Цитаты ТОЛЬКО из расшифровки. Никогда из статьи.**

| Автор | Герой |
|-------|-------|
| Текст автора | |
| | Цитата из расшифровки |

## РОЛИ АВТОРА И ГЕРОЯ
 
Роль автора: Бизнес-аналитик/журналист-расследователь, изучающий явление (рынок, бизнес-модель, индустрию). НЕ рассказывает историю героя.
 
Роль героя: Кейс-стади, пример, инсайдер, предоставляющий доказательства и детали из первых рук.
 
Ключевые принципы:
 
- Автор исследует БИЗНЕС/РЫНОК явление, а не личную историю героя
- Автор говорит об индустрии, рыночной механике, бизнес-моделях
- Цитаты героя иллюстрируют тезис автора или раскрывают инсайдерские детали
- Герой может говорить непрерывно при раскрытии сложной информации - не разрывайте его речь искусственно
- Текст автора краткий и разговорный
- НЕТ прямого обращения или диалога между автором и героем
- Если контент есть только в статье (не в расшифровке) → Автор излагает это как рыночный факт
 
Тональная разница:
 
❌ ПЛОХО: "Наш герой столкнулся с проблемой..." [рассказ истории героя]
✅ ХОРОШО: "В этом бизнесе есть проблема..." [анализ бизнеса]
❌ ПЛОХО: "Он решил сделать X..." [путь героя]
✅ ХОРОШО: "Один из способов решить это — X..." [бизнес-решение]

В начало сгенерируйте 3-5 открывающих вопросов о БИЗНЕСЕ/РЫНКЕ:
 
"Сколько на этом зарабатывают?"
"В чём главная проблема этого рынка?"
"Почему этот бизнес убыточный?"
 
КРИТИЧЕСКИ ВАЖНО: Эти вопросы должны оставаться БЕЗ ОТВЕТА до финальных эпизодов. Они создают интригу, которая удерживает видео вместе.

## ШАГ 1: Определить структуру статьи
 
### 1.1 Прочитать оба файла
 
Сначала прочитай статью полностью.  
Потом прочитай расшифровку полностью.
 
### 1.2 Выписать разделы статьи
 
Составь список разделов в порядке статьи.
 
**Формат:**
```
1. ОТКРЫТИЕ
2. [Название раздела 1]
3. [Название раздела 2]
...
N. ФИНАЛ
```
 
**Пример:**
```
1. ОТКРЫТИЕ
2. Ликбез по лизингу
3. Как открыть лизинг
4. Доходы лизинга
5. Расходы лизинга
6. Прибыль лизинга
7. ФИНАЛ
```
 
**Результат Шага 1:**  
Список разделов статьи в порядке следования.

## ШАГ 2: Для каждого раздела СНАЧАЛА выписать все цитаты героя
 
⚠️ **КРИТИЧЕСКИ ВАЖНЫЙ ПРИНЦИП: ГЕРОЙ — ПЕРВЫЙ, АВТОР — ЗАПОЛНЯЕТ ПРОБЕЛЫ.**
 
Порядок действий перевёрнут по сравнению с интуицией. НЕ пиши сначала текст автора, а потом ищи цитаты. Делай наоборот:
 
1. Берёшь раздел из Шага 1
2. Ищешь ВСЕ цитаты героя по этой теме в расшифровке (алгоритм поиска — см. ниже)
3. Выписываешь их
4. Смотришь, что осталось НЕ покрыто цитатами — ЭТО пишет автор (в Шаге 3)
 
Это предотвращает главную ошибку: автор пересказывает то, что герой может сказать сам.
 
### 2.1 АЛГОРИТМ поиска цитат для каждого раздела
 
Для каждого раздела из Шага 1:
 
**Шаг 2.1.1:** Определи тему раздела (например: "стоимость дрона")
 
**Шаг 2.1.2:** Найди в расшифровке упоминания этой темы:
- Ctrl+F по ключевым словам ("дрон", "стоит", "миллион")
- Ctrl+F по цифрам из статьи ("2200000", "два миллиона")
 
**Шаг 2.1.3:** Когда нашёл место, прочитай 2-3 абзаца вокруг
 
**Шаг 2.1.4:** Выдели ПОЛНЫЙ фрагмент:
- Начало: откуда становится понятно, о чём речь
- Конец: где мысль завершена
 
**Шаг 2.1.5:** Скопируй фрагмент ТОЧЬ-В-ТОЧЬ (Ctrl+C → Ctrl+V)
 
### 2.2 ЧТО считается ПОЛНОЙ цитатой
 
**Тест полноты:** Прочитай цитату отдельно от статьи.
 
- Понятно ли, о чём говорит герой? → **ДА = хорошо**
- Понятно ли, о какой теме? → **ДА = хорошо**
- Есть ли конкретика (цифры, детали)? → **ДА = хорошо**
 
Если хоть раз **НЕТ** → расширь цитату.
 
**Примеры:**
 
✅ **ПОЛНАЯ цитата:**
```
"дрон стоит от 2,2 млн рублей если взять сам дрон его стоимость всех узлов 1400 а на рынке дрон стоит 3 миллиона 400"
```
(Понятно: речь о дроне, о цене, конкретные цифры)
 
❌ **НЕПОЛНАЯ цитата:**
```
"3 миллиона 400"
```
(Непонятно: 3 миллиона за что?)
 
### 2.3 КРИТИЧНО: Копировать ТОЧЬ-В-ТОЧЬ
 
⚠️ **ПРАВИЛО БЕЗ ИСКЛЮЧЕНИЙ:**
 
Нажми Ctrl+C в расшифровке → Ctrl+V в таблицу.  
НИЧЕГО не меняй между копированием и вставкой.
 
**Сохраняй:**
- Ошибки ("пришел" вместо "пришёл")
- Опечатки ("вулье" вместо "улье")
- Неправильную пунктуацию
- Строчные/заглавные буквы как есть
- Пробелы и отсутствие пробелов
 
**Почему:** Пользователь будет искать цитату через Ctrl+F в расшифровке. Изменишь символ → не найдёт.
 
### 2.4 ПРИОРИТЕТЫ при выборе цитат
 
Если на одну тему НЕСКОЛЬКО цитат в расшифровке, выбирай по приоритетам:
 
**1. МАТ и эмоциональная лексика** (ВЫСШИЙ приоритет)
```
"ебало сгорело, руки засохли, сопли невкусные"
"блядь, это пиздец какой-то"
```
 
**2. ИСТОРИИ от героя**
```
"У меня один дрон пацаны разбили..."
"Ты когда-нибудь лежал с автоматом в затылок?"
```
 
**3. ПРОЦЕССЫ** (как что-то делается)
```
"Когда поле прорисовано, приезжает вода с прицепом, заливает воду, химию и начинается работа"
```
 
**4. ЦИФРЫ и конкретика**
```
"От 7 000 до 10 000 Га за сезон"
"Минус 280 тысяч рублей на ремонт"
```
 
**Если нет ни одного** → бери нейтральную, но ПОЛНУЮ цитату.
 
### 2.5 ПОДВОДКА к цитате
 
**Когда НУЖНА подводка:**
 
Прочитай:
1. Последнее предложение автора
2. Цитату героя
 
Если между ними НЕТ смысловой связи → **НУЖНА ПОДВОДКА**.
 
**Формулы подводок:**
 
```
Сколько [конкретный вопрос]?
```
 
```
Послушайте, как это работает:
```
 
```
Вот конкретный пример:
```
 
**Пример НУЖНА подводка:**
 
❌ **БЕЗ подводки (непонятная связь):**
```
| Работа тяжёлая. | |
| | от 15 до 20 |
```
(Непонятно: 15-20 чего? О чём речь?)
 
✅ **С подводкой (понятно):**
```
| Работа тяжёлая. | |
| Сколько часов работают в день? | |
| | от 15 до 20 часов, бывает и по 18 | |
```
 
**Когда НЕ нужна подводка:**
 
Если связь очевидна:
```
| Сколько стоит дрон? | |
| | дрон стоит от 2,2 млн рублей | |
```
(Вопрос → прямой ответ, подводка не нужна)
 
**Результат Шага 2:**  
Для каждого раздела выписаны ВСЕ цитаты героя по теме. Ты видишь, что покрыто героем, а что — нет.

## ШАГ 3: Написать текст автора — ТОЛЬКО для того, что НЕ покрыто цитатами
 
⚠️ **Автор заполняет пробелы. Герой — первый, автор — второй.**
 
Посмотри на результат Шага 2. Для каждого раздела ты видишь, какие темы уже покрыты цитатами героя. Теперь напиши текст автора ТОЛЬКО для того, что осталось:
 
- Краткие вводные (1-2 предложения): "Все началось с общепита."
- Переходы между темами: "А теперь о технологии."
- Вопросы в пространство: "Сколько это стоит?"
- Контент, которого НЕТ в интервью (обобщения, расчёты автора, контекст)
 
### СТОП-ТЕСТ на каждое предложение автора (ОБЯЗАТЕЛЬНО)
 
ПЕРЕД записью КАЖДОГО предложения автора выполни:
- □ Ctrl+F по ключевым словам этого предложения в расшифровке
- □ Нашёл? → Это говорит ГЕРОЙ, не автор. Замени на цитату.
- □ Не нашёл? → Автор может сказать.
- □ Это факт из опыта героя (цифра, событие, процесс)? → Даже если точной цитаты нет, проверь ещё раз — может, формулировка другая.
 
Ключевая идея: стоп-тест работает не в конце как проверка, а ВСТРОЕН в процесс генерации как обязательный шаг ПЕРЕД каждым предложением автора.
 
### 3.1 ТОН АВТОРА (КРИТИЧНО)
 
#### ЗОЛОТОЕ ПРАВИЛО №1: Автор НЕ упоминает героя
 
❌ **ЗАПРЕЩЕНО:**
- "Герой узнал..."
- "У Александра есть..."
- "Константин рассказывает..."
- "Наш герой начал..."
 
✅ **ПРАВИЛЬНО:**
- "В бизнесе на маркетплейсах нужна подушка"
- "Агродрон летает на высоте 3 метров"
 
#### ЗОЛОТОЕ ПРАВИЛО №2: НЕ говорить от первого лица
 
❌ **ЗАПРЕЩЕНО:**
- "разобрался с деньгами"
- "понял, что нужны люди"
- "узнал стоимость"
- "посчитал расходы"
 
✅ **ПРАВИЛЬНО:**
- "с финансированием понятно"
- "теперь нужны люди"
- "стоимость составляет"
- "расходы следующие"
 
**Примеры:**
 
❌ "С деньгами разобрался. Теперь нужны люди."  
✅ "С финансированием понятно. Теперь нужны рабочие руки."
 
❌ "Понял, что без бригад не обойтись."  
✅ "Без бригад не обойтись."
 
#### ЗОЛОТОЕ ПРАВИЛО №3: НЕ обращаться к читателю на "ты"
 
❌ **ЗАПРЕЩЕНО:**
- "Можешь получить кредит"
- "Не построишь без бригады"
- "Тебе нужно учесть"
 
✅ **ПРАВИЛЬНО (безличные формы):**
- "Можно получить кредит"
- "Без бригады не построить"
- "Нужно учесть"
 
✅ **ПРАВИЛЬНО (про компанию/бизнес):**
- "Компания получает кредит"
- "Застройщику нужны бригады"
- "Бизнесу требуется учесть"
 
### 3.2 АЛГОРИТМ ТРАНСФОРМАЦИИ БИОГРАФИЧЕСКОГО МАТЕРИАЛА
 
Если в статье есть биографический блок (путь героя, история создания, хронология), НЕ пересказывай его. Вместо этого:
 
**Шаг А:** Определи, какую БИЗНЕС-МЕХАНИКУ этот блок иллюстрирует.
 
```
"Начал с игровых автоматов" → бизнес-механика: низкий порог входа в вендинг.
"Продал квартиру ради бизнеса" → бизнес-механика: высокий порог входа, нужен стартовый капитал.
```
 
**Шаг Б:** Сформулируй тезис автора о МЕХАНИКЕ, а не о герое.
 
```
❌ "Так начинался путь в вендинг: с игровых автоматов"
✅ "В вендинг можно войти с минимальным капиталом."
```
 
**Шаг В:** Биографическую деталь — в цитату героя из расшифровки.
 
**Шаг Г:** Если не можешь определить бизнес-механику → блок не нужен в сценарии. **Удали.**
 
**Полный пример трансформации:**
 
❌ ПЛОХО (биография):
```
| Автор | Герой |
| Александр начал с игровых автоматов в 2010 году. Потом перешёл на вендинг. | |
```
 
✅ ХОРОШО (бизнес-механика + цитата):
```
| Автор | Герой |
| В вендинг часто приходят из смежных ниш — порог входа низкий. | |
| | я начал с игровых автоматов потом понял что вендинг это то же самое только легально | расшифровка, 05:20 |
```
 
### 3.3 СТИЛЬ ТЕКСТА АВТОРА
 
#### Смысловые мостики и действующие лица
 
Каждый абзац связан логически с предыдущим.
 
Указано, кто именно выполняет действия: не "огневые испытания проводятся", а "компания проводит огневые испытания" или "лизинг проводит испытания".
 
❌ Плохо: Огневые испытания проводятся по стандарту.  
✅ Хорошо: Лизинговая компания проводит огневые испытания по стандарту.
 
Внутри секции есть причинно-следственные связи: не просто что делается, а зачем.
 
#### Язык и выразительность
 
**Не используй пассивный залог. Пишите активным залогом:**
 
❌ Плохо: "Медь травится", "Система была разработана", "В конструкциях использовались разные утеплители"  
✅ Хорошо: "Компания травит медь", "Компания разработала систему", "Компании используют разные утеплители"
 
**Избегайте отглагольных существительных:**
 
❌ Плохо: "выполняем сверление", "производим работы по строительству сетей"  
✅ Хорошо: "сверлим отверстия", "строим сети"
 
**Разбивайте сложные предложения на простые.**
 
Простые предложения с логическими связками: если → то, сначала → потом.
 
**Исключите слова-паразиты и усилители:** «реально», «очень», «максимально».
 
**Абстрактные оценки заменяем конкретикой:**
 
❌ Плохо: "высокая точность", "существенный рост прибыли"  
✅ Хорошо: "допуск — 0,05 мм", "прибыль выросла на 28%"
 
#### Подача информации
 
Используйте точные цифры с контекстом — "Увеличили конверсию с 2,3% до 3,8% за 14 дней".
 
❌ Плохо: «металлизация 25 мкм»  
✅ Хорошо: «металлизация 25 мкм — это минимум по стандарту IPC класса 3»
 
Процессы — в виде пошагового сценария: «сначала делаем А, затем Б, в конце — В».
 
Показывайте реальные результаты, включая неудачи — "Первый запуск привлек только 17 клиентов".
 
#### Технические термины
 
При первом упоминании любого технического термина, аббревиатуры или обозначения сразу объясняй его простыми словами. Не заставляй читателя гадать или искать расшифровку в других частях текста. Принцип: термин появился — сразу объяснил.
 
Пиши точно, без искажения смысла. Не подменяй термин бытовым аналогом («не горючий» ≠ «не горит»).
 
– Допускается аналогия, но только после точного объяснения, и если она короткая и помогает понять.
 
❌ Плохо: заменить определение, чтобы упростить «Препрег — это как двухсторонний скотч».  
✅ Хорошо: ты не заменяешь определение, а добавляешь пример после него. «Препрег — это стеклоткань с пропитанной смолой. При нагреве она плавится и соединяет слои. Можно представить это как двухсторонний скотч — только в инженерной версии».
 
– Показывай, зачем это нужно в реальности. Не просто: «так принято», а «если не сделать — будет ошибка/брак/дефект».
 
Расчёты поясняем словами: «Если слой меди тоньше, сигнал может искажаться на высокой частоте».
 
#### Структура текста
 
Начинайте с главного — помещайте ценную информацию в начало текста.
 
Абзацы короткие, от 1 до 4 предложений — по смыслу.
 
Чередуйте фактическую информацию с пояснениями.
 
#### Избегайте
 
Канцелярита и официоза: не «осуществляем контроль», а «проверяем», вместо "осуществляем использование" пищи "используем".
 
Штампов: не «высокотехнологичное решение», а «медь толщиной 35 мкм», вместо "титанические усилия" пиши "упорный труд".
 
Избыточных причастий и деепричастий — они утяжеляют текст: не «металлизированная при помощи гальванического метода», а «компания осаждает медь с помощью гальваники».
 
Эмоционального пафоса: никакого «невероятно точного», «вдохновляющего опыта».
 
Преувеличений и необоснованных заявлений — "лучший в мире", "уникальный", "невероятный", "жесткий стандарт". Вместо этого напиши конкретику: "Огневые испытания проводят по государственному стандарту ГОСТ 30247.1-94".
 
Пустых вводных конструкций — "следует отметить", "необходимо подчеркнуть".
 
Неестественной эмоциональности — восклицательные знаки и капслок.
 
### 3.4 Объяснение терминов
 
**Правило:** Объясняй термин В ТОМ ЖЕ предложении, где используешь.
 
**Формула:**
```
[Термин] — это [объяснение в 3-5 словах].
```
 
**Примеры:**
 
✅ "Агродрон — это маленький беспилотный вертолёт для обработки полей."  
✅ "РЭБ — это радиоэлектронная борьба, средство подавления дронов."  
✅ "Десикация — это высушивание растений перед уборкой."
 
❌ "Нужна десикация." (не объяснено)  
❌ "РЭБ мешает работе." (не объяснено)
 
### 3.5 СВЯЗКИ между разделами
 
**Формула связки (3 предложения):**
 
```
[Итог предыдущего]. [Зачем следующее]. [Что дальше].
```
 
**Пример:**
 
```
Теперь понятно, как открыть лизинг.
Но сколько можно заработать?
Давайте посчитаем доходы.
```
 
**Результат Шага 3:**

### 3.6 Правила для вопросов автора
 
1. Вопросы В ПРОСТРАНСТВО - хорошо:
 
"Как это работает?"
"Что происходит дальше?"
"Почему так дорого?"
"Сколько на этом зарабатывают?"
 
2. Вопросы К ГЕРОЮ - плохо:
 
Не задавайте вопросы сразу после цитаты героя
Не реагируйте на слова героя ("Значит, вы имеете в виду...", "То есть...")
Не создавайте паттерн вопрос-ответ, где герой "отвечает" автору
 
3. Не реагируйте на героя:
 
❌ "Получается", "То есть", "Значит" сразу после цитаты героя
✅ Излагайте факты независимо
 
### Паттерн, которого следует избегать:
```
Автор: [вопрос]
Герой: [ответ]
Автор: [уточняющий вопрос]
Герой: [ответ]
```
Это создаёт ощущение интервью, а не документального расследования.
 
### Правильный паттерн:
```
Автор: [констатирует явление/задаёт вопрос в пространство]
Герой: [предоставляет доказательство/пример]
Автор: [продолжает расследование независимо]
Герой: [предоставляет другой угол]
```

## ШАГ 6: Проверить на повторы
 
### 6.1 ПРАВИЛО: Один факт = одно место
 
Прочитай таблицу целиком.
 
Для каждого ФАКТА проверь: упоминается ли он больше одного раза?
 
**Факты для проверки:**
- Конкретные цифры ("2,2 млн", "8,5 млн")
- Определения терминов ("агродрон — это...")
- Истории героя
- Процессы
 
### 6.2 Что делать с повторами
 
**Если факт повторяется:**
 
**Вариант 1:** Удали менее удачное упоминание
 
**Вариант 2:** Первый раз — полное, второй раз — краткое напоминание
 
**Пример:**
 
✅ **ПРАВИЛЬНО:**
```
[Раздел 2]
| Дрон стоит от 2,2 миллиона рублей. | |
 
[Раздел 5]
| Вспомним: дрон стоит от 2,2 миллиона. | |
```
 
❌ **НЕПРАВИЛЬНО:**
```
[Раздел 2]
| Дрон стоит от 2,2 миллиона рублей. | |
 
[Раздел 5]
| Дрон стоит от 2,2 миллиона рублей. | |
```
 
### 6.3 Алгоритм проверки
 
**Шаг 6.3.1:** Ctrl+F по ключевым цифрам ("2,2", "8,5")
 
**Шаг 6.3.2:** Сколько раз упоминается?
- 1 раз → хорошо
- 2+ раза → проверить, нужны ли оба
 
**Шаг 6.3.3:** Если оба нужны:
- Первый раз → оставить полностью
- Второй раз → сократить до "Вспомним: ..."

## ШАГ 7: Проверить связность
 
### 7.1 Читай таблицу ПОСЛЕДОВАТЕЛЬНО
 
Прочитай таблицу от начала до конца как единый текст.
 
### 7.2 Проверь ЛОГИКУ
 
**Вопросы при чтении:**
 
1. **Понятен ли переход между разделами?**
   - Если НЕТ → добавь связку
 
2. **Есть ли резкие скачки тем?**
   - Если ДА → добавь объяснение, зачем переходим
 
3. **Объяснены ли термины ДО использования?**
   - Если НЕТ → добавь объяснение
 
4. **Автор не говорит от первого лица?**
   - Если говорит → переформулируй
 
5. **Автор не обращается на "ты"?**
   - Если обращается → сделай безличную форму
 
6. **Автор не упоминает героя?**
   - Если упоминает → переформулируй
 
7. **Автор не пересказывает то, что есть в расшифровке?**
   - Если пересказывает → замени на цитату героя
 
8. **Автор не реагирует на героя словами "получается", "то есть", "значит"?**
   - Если реагирует → убери реакцию
 
9. **Текст автора написан активным залогом?**
   - Если пассивный → переформулируй
 
10. **Нет отглагольных существительных?**
   - Если есть → замени на глаголы
 
11. **Нет канцелярита и штампов?**
   - Если есть → замени на конкретику
 
12. **Абстракции заменены на конкретику?**
   - Если нет → добавь цифры и контекст
 
### 7.3 Проверь БАЛАНС (финальная верификация)
 
Основной контроль баланса выполнялся в Шаге 4.3 по каждому эпизоду. Здесь — финальная проверка по всему сценарию целиком.
 
Посчитай примерно:
 
**Строк автора:** ___ шт.  
**Строк героя (цитат):** ___ шт.
 
**Хорошее соотношение:** 40% автор / 60% герой
 
Если сильно не так:
- Мало героя → вернись к конкретным эпизодам, где перекос, и добавь цитаты
- Много автора → найди, где автор пересказывает то, что герой может сказать сам, и замени на цитаты
- **Не ограничивайся формальной пометкой** "68/32, рекомендуется добавить цитаты" — реально переработай проблемные эпизоды
 
### 7.4 Тест "ПРОЧИТАТЬ ВСЛУХ"
 
Прочитай несколько разделов вслух (или про себя):
 
- Звучит ли естественно?
- Нет ли спотыканий?
- Ясна ли логика?
- Нет ли ощущения интервью (вопрос-ответ)?
