# Сценарий видео для YouTube

Формат: автор (Слава) исследует бизнес-тему, герой даёт инсайды из интервью. Цепочка создания ценности от сырья до потребителя.

## Когда НЕ использовать
- Нет расшифровки интервью (только статья)
- Видео без героя (монолог автора)
- Формат не про бизнес/деньги

## Шаг 0: Чтение материалов

Прочитать:
- `<project_dir>/raw/article.md` — статья
- `<project_dir>/transcripts/*.transcript.txt` — расшифровки интервью

Если `<project_dir>` не передан — спросить у пользователя.

## Шаг 1: Таблица цифр

⛔ НЕ ПИСАТЬ СЦЕНАРИЙ, пока не выполнен этот шаг.

1. Выписать ВСЕ цифры из материалов в таблицу: значение, источник (статья/расшифровка)
2. Показать пользователю, дождаться подтверждения

**Золотое правило:** НИКОГДА не придумывать цифры.
- Есть в материалах → использовать
- Можно рассчитать → пометить [РАСЧЁТ] с формулой
- Нет данных → пометить [НУЖНО УТОЧНИТЬ]
- НЕ округлять без обоснования, НЕ путать опт и розницу

Развёрнутые примеры: см. youtube-script-examples.md, секции «Таблица цифр» и «Ошибки с цифрами».

## Шаг 2: Фокус исследования

1. **Денежный вопрос** — трансформировать «как я открыл бизнес X» в «почему X стоит так дорого?»
2. **Цепочка создания ценности** — от сырья до потребителя (4-7 участников)
3. **Место героя** — один из участников цепочки, не центр истории
4. **3-5 открывающих вопросов** — остаются БЕЗ ОТВЕТА до финала
5. **Трёхактная структура:**
   - Акт 1 (завязка): большие вопросы + начало ответов КАК
   - Акт 2 (развитие): детали, расчёты, технология
   - Акт 3 (развязка): ответы на вопросы из открытия, цифры прибыли

Показать пользователю, дождаться подтверждения.

## Шаг 3: Написание сценария

### Правила цитат
- Источник — ТОЛЬКО расшифровки интервью (НЕ статья)
- Copy-paste БЕЗ редактирования (сохранять ошибки, повторы, междометия)
- Приоритет самодостаточным цитатам (герой сам даёт контекст)
- Несамодостаточные цитаты — только с ПОЛНОЙ подводкой автора (все термины объяснены до цитаты)

### Правила распределения
- 70% герой (цитатами), 30% автор (вводные, переходы, расчёты)
- Если информация есть в расшифровке → герой говорит сам, автор НЕ пересказывает

### Правила доступности
- Смысловые мостики между темами: итог предыдущей → почему переходим → новая тема
- Каждый термин/название/понятие объяснить ДО использования
- Вопросы автора — в пространство, не к герою лично. Без «герой ответил», «давайте спросим у героя»

### Язык
- Числа как произносятся: «два рубля сорок копеек», не «2,4 рубля»
- После расчётов: «Итого: [вывод]»
- Короткие предложения, активный залог, без канцеляризмов

Развёрнутые примеры ко всем правилам: см. youtube-script-examples.md.

## Шаг 4: Сохранение

Сохранить в `<project_dir>/script/script_draft.csv`.
Формат: 4 колонки — `Слава,Таймкоды,Герой,Таймкоды`.
Заполнить только колонки 1 (Слава) и 3 (Герой). Колонки 2 и 4 — пустые (заполняются пайплайном позже).
Строки-заголовки разделов — в первой колонке.

## Шаг 5: Финальная проверка

- [ ] Каждая цифра из таблицы (Шаг 1) или помечена [РАСЧЁТ]/[НУЖНО УТОЧНИТЬ]
- [ ] Все цитаты — дословный copy-paste из расшифровок
- [ ] Самодостаточные цитаты использованы где возможно
- [ ] Несамодостаточные — с полной подводкой
- [ ] 70% герой / 30% автор
- [ ] Автор не пересказывает то, что герой сказал в интервью
- [ ] Смысловые мостики перед каждым переходом
- [ ] Все термины объяснены до использования
- [ ] Нет диалоговых паттернов
- [ ] Числа читаются вслух
- [ ] CSV сохранён, формат корректный
