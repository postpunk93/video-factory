# Примеры для скилла youtube-script

Этот файл содержит развёрнутые примеры хорошо/плохо для правил скилла youtube-script.

---

## Таблица цифр — пример

```
ТАБЛИЦА ЦИФР ИЗ МАТЕРИАЛОВ:

ЗЕЛЁНОЕ ЗЕРНО:
- В Эфиопии: 490 ₽/кг [источник: статья]
- В Питере: 660 ₽/кг [источник: статья]
- Разница (логистика): 170 ₽/кг [расчёт: 660-490]

ОБЖАРКА:
- Ужарка: 20% [источник: расшифровка, файл X, 18:39]
- Для 1 кг обжаренного нужно: 1,25 кг зелёного [расчёт: 1/(1-0,2)]
- Упаковка: 40 ₽ [источник: расшифровка, файл X, 19:33]
- Электричество: 5 ₽/кг [источник: расшифровка, файл X, 19:33]
- Доставка до Ижевска: 15 ₽/кг [источник: расшифровка, файл X, 19:33]

ПРОДАЖА:
- Опт: 1126 ₽/кг [источник: статья]
- Розница: 1733 ₽/кг [источник: статья]
- Налоги и зарплаты: 12% от продажи [источник: расшифровка, файл X, 19:33]

РАСХОДЫ ПРОИЗВОДСТВА:
- Аренда: 350 000 ₽/месяц [источник: статья]
- Коммуналка: 250 000 ₽/месяц [источник: статья]
...и так далее для ВСЕХ цифр
```

## Ошибки с цифрами

**1. Округление "на глазок"**

❌ **ПЛОХО:** «Обжарщик продаёт килограмм за 1500 рублей» (в таблице: опт 1126 ₽, розница 1733 ₽ — откуда 1500?)
✅ **ХОРОШО:** «Килограмм обжаренного кофе стоит для кофейни в опт 1126 рублей»

**2. Перепутал опт и розницу**

❌ **ПЛОХО:** «Прибыль обжарщика — около 240 рублей с килограмма» (использовал розничную цену 1733 ₽, но кофейня покупает опт)
✅ **ХОРОШО:** «Прибыль обжарщика в опте — около 101 рубля с килограмма. В рознице наценка выглядит гораздо лучше, но её съедают затраты на маркетинг»

**3. Цепочка неправильных расчётов**

❌ **ПЛОХО:**
```
Прямая себестоимость — около 885 рублей.
Обжарщик продаёт за 1500 рублей.
Разница — примерно 615 рублей.
```
(первая цифра неверна → все последующие расчёты неверны)

✅ **ХОРОШО:**
```
Прямая себестоимость — 889 рублей (из статьи).
Обжарщик продаёт в опт за 1126 рублей (из статьи).
Разница — 237 рублей [РАСЧЁТ: 1126 - 889].
```

**4. Придумывание итоговых цифр**

❌ **ПЛОХО:** «Итого: из 300 рублей кофейне остаётся 30-50 рублей прибыли» (откуда 30-50? Этой цифры нет в материалах)
✅ **ХОРОШО:** «Итого: из 300 рублей кофейне остаётся прибыль [НУЖНО УТОЧНИТЬ — в материалах нет данных о прибыли кофейни]»

## Цитаты: самодостаточные vs несамодостаточные

### Правило 3: Приоритет самодостаточных цитат

**АЛГОРИТМ выбора цитат (применяй КАЖДЫЙ РАЗ):**

**ШАГ 1:** Поищи в расшифровке **самодостаточную цитату**

Самодостаточная = герой САМ проговаривает весь контекст.

**ТЕСТ:** Закрой текст автора. Прочитай только цитату. Понятно ли О ЧЁМ речь?

✅ **Пример самодостаточной цитаты:**
```
| | Китайцы начинают поставлять в Россию велики уже либо на зимней резине либо на всесезонке да мы сталкиваемся с тем что мы покупаем дополнительные перебортовые одно колесо стоит порядка двух с половиной тысяч рублей | filename.txt, 12:34-12:50 |
```
(понятно: о чём речь, кто поставляет, что за проблема, сколько стоит)

**Если такая цитата есть → используй её.** Подводка минимальная или не нужна.

**ШАГ 2:** Если самодостаточной цитаты НЕТ → автор делает **ПОЛНУЮ подводку**

Несамодостаточная цитата = содержит термины/контекст, которых герой не объясняет в этом фрагменте.

❌ **ПЛОХО (несамодостаточная цитата БЕЗ подводки):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| При обжарке кофе теряется вес. | | |
| | От 15 до 20, смотря какое. Рабуста, да, 20% будет в жарках, потому что ее сильно надо жарить. | interview.txt, 08:15-08:23 |
```
**Проблемы:**
- Что такое "15-20"? (автор не сказал, что это проценты)
- Что такое "рабуста"? (термин не объяснён)
- Связь непонятна

✅ **ХОРОШО (несамодостаточная цитата + ПОЛНАЯ подводка):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| При обжарке кофе теряется вес. Это называется ужарка. | | |
| Есть два основных вида кофе: арабика — более дорогая и качественная, и робуста — дешёвая и крепкая. | | |
| Сколько процентов веса теряется при обжарке? | | |
| | От 15 до 20, смотря какое. Рабуста, да, 20% будет в жарках, потому что ее сильно надо жарить. | interview.txt, 08:15-08:23 |
```
Теперь понятно:
- "15-20" = проценты (автор задал вопрос)
- "рабуста" = вид кофе (автор объяснил)
- Связь ясна

**ПРАВИЛО:**

**Приоритет 1:** Ищи самодостаточные цитаты (герой сам всё объясняет)

**Приоритет 2:** Если самодостаточной нет — можно взять несамодостаточную, НО:
- Автор ОБЯЗАН объяснить ВСЕ термины до цитаты
- Автор ОБЯЗАН дать контекст
- Автор ОБЯЗАН задать вопрос или дать подводку

**ЗАПРЕЩЕНО:** Брать несамодостаточную цитату БЕЗ подводки

**КАК ИСКАТЬ самодостаточные цитаты:**

1. Ищи **длинные фрагменты** в расшифровке (5-10 предложений)
2. Герой часто САМ объясняет всё, когда рассказывает историю или процесс
3. Обрати внимание на фрагменты, где герой говорит:
   - "Смотри, как это работает..."
   - "Вот конкретный пример..."
   - "У нас, например, такая ситуация..."

Эти фрагменты обычно самодостаточны.

## Подводки к цитатам

### Правило 4: Подводки к цитатам (ОБЯЗАТЕЛЬНЫЙ ТЕСТ)

**ОБЯЗАТЕЛЬНЫЙ ТЕСТ для каждой цитаты:**

1. Прочитай текст автора
2. Затем сразу цитату героя
3. Если возникает вопрос "А при чём тут это?" или "Как это связано?" → **НУЖНА ПОДВОДКА**

**Структура ОБЯЗАТЕЛЬНА:**
```
| Автор задаёт вопрос ИЛИ даёт контекст | | |
| | ЦИТАТА ГЕРОЯ | файл, тайминг |
```

❌ **ПЛОХО (без подводки, непонятная связь):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Фермеры в Африке получают очень мало денег за свой труд. | | |
| | у меня был один случай я не доказал но я точно знаю что там была схема с документами через Панаму понимаешь | interview.txt, 12:34-12:45 |
```
(Зритель думает: "Причём тут Панама? О чём вообще речь?")

✅ **ХОРОШО (с подводкой, всё понятно):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Фермеры в Африке получают очень мало денег за свой труд. | | |
| Вот что говорит герой про реальные выплаты фермерам: | | |
| | в Руанде фермер получает доллар в день это не шутка доллар в день я сам видел эти фермы и говорил с людьми | interview.txt, 12:50-12:58 |
```

**Шаблоны подводок:**
- "Вот что говорит герой про [тема]:"
- "Послушайте, как это работает на практике:"
- "Герой объясняет, в чём проблема:"
- "Вот конкретный пример:"
- "Сколько [конкретный вопрос]?"

**Когда подводка НЕ нужна:** Если связь очевидна — не добавляй лишнее.

✅ **ХОРОШО (без подводки, связь ясна):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Сколько фермер получает за килограмм кофе? | | |
| | фермер получает примерно 50 центов за килограмм иногда даже меньше | interview.txt, 08:15-08:21 |
```

## Распределение контента: антипаттерны

**Золотое правило:** Если информация ЕСТЬ в расшифровке интервью → Герой говорит это сам (цитатой). Не пересказывай автором то, что герой может сказать.

### Распределение контента - пошаговая логика:

**ШАГ 1: Смотришь на кусок контента из статьи**

**ШАГ 2: Проверяешь - есть ли это в расшифровке?**

✅ **ЕСТЬ в расшифровке** → Герой говорит цитатой
- Факты из личного опыта героя
- Цифры, которые называл герой
- Процессы, которые описывал герой
- Проблемы, о которых рассказывал герой
- Эмоции, инсайты, мнения героя

❌ **НЕТ в расшифровке** → Автор рассказывает
- Обобщения и выводы, сделанные автором статьи
- Расчеты, которые автор сделал сам
- Контекст и объяснения, добавленные автором
- Сравнения и аналогии от автора
- Информация из других источников

**ШАГ 3: Автор делает только:**
- Краткие вводные (1-2 предложения): "Все началось с общепита."
- Переходы между темами: "А теперь о технологии."
- Вопросы в пространство: "Сколько это стоит?"
- Контент, которого НЕТ в интервью

### ❌ АНТИПАТТЕРНЫ (так делать НЕЛЬЗЯ):

**Плохо:**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Первый ростер купили непонятный какой-то. Не знали про них ничего. | | |
| | Взяли ростер, непонятный какой-то там, да? Мы не знали про них ничего. | interview.txt, 10:00 |
```

❌ **Проблема:** Автор ПЕРЕСКАЗЫВАЕТ то, что есть в интервью. Потом герой повторяет то же самое.

**Хорошо:**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Первый ростер... | | |
| | Взяли ростер, непонятный какой-то там, да? Мы не знали про них ничего. Просто ростер какой-то. По цене вроде нормально. Компьютер его не подключить было, да? То есть профили обжарки одинаковые не сделать. | interview.txt, 10:00-10:20 |
```

✅ **Правильно:** Автор только вводит тему одним словом. Герой сам рассказывает всё.

### Алгоритм проверки каждой строки:

Перед тем как написать реплику автора, спроси себя:

1. **Есть ли эта информация в расшифровке?**
   - Да → Дай герою сказать это цитатой
   - Нет → Автор может это рассказать

2. **Это факт из опыта героя?**
   - Да → Герой говорит
   - Нет → Автор может

3. **Могу ли я найти цитату героя об этом?**
   - Да → Используй цитату героя
   - Нет → Автор рассказывает

4. **Я пересказываю автором то, что герой сказал в интервью?**
   - Да → СТОП! Используй цитату героя вместо пересказа
   - Нет → Ок, автор может

### Правильные пропорции контента:

В хорошем сценарии:
- **70% времени говорит Герой** (цитатами из интервью)
- **30% времени говорит Автор** (вводные, переходы, расчеты)

Если у тебя получается наоборот → ты неправильно распределяешь контент.

## Смысловые мостики

### Правило 1: Смысловые мостики между темами

**Проблема:** Текст перескакивает с темы на тему без объяснения, почему мы это делаем. Зритель теряется и не понимает логику повествования.

❌ **ПЛОХО:**
```
| Автор | Герой | Файл |
|-------|-------|------|
| На сам кофе уходит около 15 рублей — это 10 граммов обжаренного зерна по оптовой цене. | | |
| Обжарщик покупает зелёное зерно в России за 660 рублей. | | |
```
**Что не так:** говорили о кофейне, потом резко заговорили об обжарщике. Непонятно, кто это и причём тут он.

✅ **ХОРОШО:**
```
| Автор | Герой | Файл |
|-------|-------|------|
| На сам кофе уходит около 15 рублей — это 10 граммов обжаренного зерна по оптовой цене. | | |
| Теперь, когда мы знаем, сколько зарабатывает кофейня, нужно понять, откуда она берёт сам кофе. Для этого спустимся на уровень ниже — к обжарщику. | | |
| Кофейня покупает готовый обжаренный кофе у компании, которая называется обжарщик. Обжарщик — это производство, которое превращает зелёные зёрна в коричневые, которые вы видите в магазине. | | |
```

**Правило смысловых мостиков:** Перед каждым переходом к новой теме нужно:
1. Подвести итог предыдущей части («Теперь мы знаем, сколько зарабатывает кофейня»)
2. Объяснить, почему переходим к следующей теме («Нужно понять, откуда кофейня берёт кофе»)
3. Представить новую тему («Для этого спустимся к обжарщику»)

**Шаблоны для мостиков:**
- «Теперь, когда мы знаем X, нужно понять Y»
- «Мы разобрались с X. Но откуда берётся Y?»
- «Чтобы понять X, нужно сначала разобраться с Y»
- «Это объясняет X. Теперь посмотрим на Y»
- «После X логично спросить: а как обстоит дело с Y?»

## Введение новой информации

### Правило 2: Вводи информацию последовательно

**Проблема:** В тексте появляются термины, названия стран, цифры, понятия, которые не были введены ранее. Зритель не понимает, откуда они взялись и что означают.

❌ **ПЛОХО:**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Обжарщик покупает зелёное зерно в России за 660 рублей. Но в Эфиопии это зерно стоит 490 рублей. | | |
```
**Что не так:** Эфиопия появилась из ниоткуда. Почему именно эта страна? Не объяснено, что кофе вообще приезжает из других стран.

✅ **ХОРОШО:**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Обжарщик покупает зелёное зерно — то есть необжаренный кофе — в России. | | |
| Кофе не растёт в России, его привозят из других стран: из Бразилии, Колумбии, Эфиопии, Вьетнама. | | |
| Компании, которые занимаются ввозом кофе в Россию, называются импортёрами. | | |
| Сейчас мы посчитаем, сколько зарабатывает импортёр на доставке кофе из Эфиопии — это одна из главных стран, откуда везут качественный кофе. | | |
| Килограмм зелёного зерна в России стоит обжарщику 660 рублей. Но в самой Эфиопии это же зерно стоит 490 рублей. | | |
```

**Правило введения новой информации:** Каждый раз, когда вводишь новое понятие, термин или название:
1. Сначала объясни общий контекст («Кофе привозят из других стран»)
2. Потом перечисли несколько примеров («Бразилия, Колумбия, Эфиопия»)
3. Объясни, почему выбрал именно этот пример («Возьмём Эфиопию — одну из главных стран»)
4. Дай определение, если это термин («Импортёр — это компания, которая...»)

### Правило 3: Объясняй все типы информации

**Технические термины:**

❌ **ПЛОХО:** «Ростер на 30 кг — 4,5 миллиона. Колосортер — 2 миллиона.»

✅ **ХОРОШО:** «Ростер — это специальная машина для обжарки кофе. Самые современные модели жарят зёрна потоками горячего воздуха. Ростер на 30 кг стоит 4,5 миллиона рублей. После обжарки кофе проходит очистку. Колосортер — это машина с фотоэлементами, которая распознаёт каждое зерно и выбивает бракованные. Она стоит 2 миллиона рублей.»

**Названия и места:**

❌ **ПЛОХО:** «Фермеры в Руанде получают один доллар в день.»

✅ **ХОРОШО:** «Давайте посчитаем, сколько зарабатывает типичный фермер в Эфиопии или Руанде — странах, где выращивают кофе. Фермеры там получают один доллар в день.»

**Виды и типы:**

❌ **ПЛОХО:** «Если закидываешь робусту вместо арабики — экономишь деньги.»

✅ **ХОРОШО:** «Существует два основных вида кофе: арабика и робуста. Арабика — более качественная и вдвое дороже робусты. Но робуста даёт горечь и не такой приятный вкус. Некоторые производители мешают дешёвую робусту с дорогой арабикой, чтобы сэкономить.»

**Процессы и технологии:**

❌ **ПЛОХО:** «20% ужарки — это уже 1200 рублей.»

✅ **ХОРОШО:** «Когда кофе обжаривается, он теряет вес — из него выходит влага. Это называется ужарка. Она составляет около 20%. То есть чтобы получить 1 килограмм готового кофе, нужно взять 1,25 килограмма зелёного.»

**Проверочный вопрос:** Перед тем как написать любой термин, название или понятие, спроси себя: «Откуда зритель должен знать, что это такое?» Если ответ «никак не должен» — нужно объяснить.

**Чек-лист:** Перед каждой цитатой проверить — все ли термины в ней уже объяснены?

## Диалоговые паттерны (антипаттерн)

### Правило 4: Избегай диалоговых паттернов

**Проблема:** Текст звучит как диалог между автором и героем, хотя это должен быть рассказ наблюдателя.

❌ **ПЛОХО (диалоговые паттерны):**
- "Я спросил героя, как он начинал..."
- "Герой ответил, что..."
