# Техническое задание
## Автоматизация видеомонтажа: паузорез
Версия 1.0 · Claude Code

---

## 1. Контекст и задача

Сотрудник собирает видео вручную: смотрит запись, вручную находит и вырезает паузы, оговорки и слова-паразиты. На одно видео уходит несколько часов.

Цель: автоматизировать первый и самый трудоёмкий этап — очистку речи — с помощью скрипта на Python. Скрипт должен принять видеофайл и вернуть видео без мусора.

> Контент — русскоязычные интервью. Спикер один. Задача первого этапа: убрать паузы, слова-паразиты и нечленораздельные звуки.

---

## 2. Технологический стек

Весь стек работает локально, бесплатно, без облаков:

- **faster-whisper** — транскрипция с тайм-кодами по каждому слову
- **ffmpeg** — вырезание фрагментов и склейка видео
- **Python 3.8+** — оркестрация логики

> faster-whisper работает в 4× быстрее оригинального Whisper при той же точности. Модель medium (~1.5 ГБ) скачивается один раз и работает офлайн.

## 4. Скрипт cut_pauses.py

Скрипт находится в папке `_scripts/`. Размещение:

```
factory/_scripts/cut_pauses.py
```

### 4.1 Установка зависимостей

Выполнить один раз:

```bash
pip install faster-whisper

# ffmpeg должен быть установлен в системе:
# macOS:   brew install ffmpeg
# Ubuntu:  sudo apt install ffmpeg
# Windows: скачать с ffmpeg.org и добавить в PATH
```

### 4.2 Что вырезает скрипт

- Паузы между словами длиннее порога (по умолчанию 0.5 сек)
- Слова-паразиты: ну, вот, это, эм, короче, типа, значит, как бы, так сказать и др.
- Повторы-запинки: «я я хотел», «и и вот»
- Шумовые токены Whisper: [вздох], [кашель], [смех] и аналоги

### 4.3 Использование

```bash
# Из папки _scripts/:
python cut_pauses.py ../projects/2025-01-название/01_raw/interview.mp4

# Результат сохраняется рядом с исходником:
# ../projects/2025-01-название/01_raw/interview_clean.mp4

# Указать папку назначения явно:
python cut_pauses.py input.mp4 --output ../02_cuts/interview_clean.mp4
```

### 4.4 Параметры

| Параметр | Описание |
|---|---|
| `--model medium` | Модель Whisper. medium — баланс скорости и точности для русского языка |
| `--model large-v3` | Лучшее качество. Медленнее, скачивает ~3 ГБ один раз |
| `--pause 0.5` | Вырезать паузы дольше 0.5 сек. Можно уменьшить до 0.3 или увеличить до 0.8 |
| `--dry-run` | Только показать что будет вырезано, файл не трогать. Использовать для проверки |
| `--save-transcript` | Сохранить транскрипцию в JSON рядом с видео — для отладки и субтитров |
| `--output path.mp4` | Указать имя выходного файла. По умолчанию: input_clean.mp4 |

### 4.5 Рекомендуемый рабочий процесс

При первом запуске на новом спикере:

1. Запустить с `--dry-run` — посмотреть отчёт, что будет вырезано
2. Оценить процент вырезаемого. Норма: 10–30% длины видео
3. Если вырезается слишком много — увеличить `--pause` до 0.7–0.8
4. Если пауз остаётся много — уменьшить до 0.3–0.4
5. Запустить без `--dry-run` с найденным оптимальным порогом
6. Скопировать результат в папку `02_cuts/`

## 5. Задача для Claude Code

Скрипт `cut_pauses.py` написан и протестирован. Задача Claude Code — настроить окружение, проверить работу скрипта на тестовом файле и при необходимости доработать под конкретного спикера.

### 5.1 Что нужно сделать

- Создать файловую структуру из раздела 3 в рабочей директории
- Разместить `cut_pauses.py` в папке `_scripts/`
- Установить зависимости: `faster-whisper`
- Запустить скрипт на тестовом видео с `--dry-run` и показать отчёт
- Подобрать оптимальный параметр `--pause` под конкретного спикера
- Обработать тестовое видео и положить результат в `02_cuts/`

### 5.2 Будущие этапы (не в этом ТЗ)

- `merge_clips.py` — склейка нескольких кусков в одно видео
- `add_subtitles.py` — генерация .srt субтитров из транскрипции Whisper
- `make_thumbnail.py` — автогенерация превью
- Оркестратор — запуск всего pipeline одной командой

> Список слов-паразитов в скрипте можно расширить. Переменная `FILLER_WORDS` в начале файла — добавить нужные слова в набор.

## 6. Критерии готовности

- Структура папок создана
- Скрипт запускается без ошибок
- `dry-run` выдаёт читаемый отчёт с процентом вырезаемого
- Обработанное видео воспроизводится без артефактов
- Речь в результирующем видео звучит естественно — без резких склеек
