# Примеры формата для сценария

Этот файл содержит примеры хорошо/плохо для правил, где без примера модель ошибается.

---

## Цитаты: самодостаточные vs несамодостаточные

**АЛГОРИТМ выбора цитат (применяй КАЖДЫЙ РАЗ):**

**ШАГ 1:** Поищи в расшифровке **самодостаточную цитату**

Самодостаточная = герой САМ проговаривает весь контекст.

**ТЕСТ:** Закрой текст автора. Прочитай только цитату. Понятно ли О ЧЁМ речь?

✅ **Пример самодостаточной цитаты:**
```
| | Китайцы начинают поставлять в Россию велики уже либо на зимней резине либо на всесезонке да мы сталкиваемся с тем что мы покупаем дополнительные перебортовые одно колесо стоит порядка двух с половиной тысяч рублей |
```
(понятно: о чём речь, кто поставляет, что за проблема, сколько стоит)

**Если такая цитата есть → используй её.** Подводка минимальная или не нужна.

**ШАГ 2:** Если самодостаточной цитаты НЕТ → автор делает **ПОЛНУЮ подводку**

❌ **ПЛОХО (несамодостаточная цитата БЕЗ подводки):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| При обжарке кофе теряется вес. | | |
| | От 15 до 20, смотря какое. Рабуста, да, 20% будет в жарках, потому что ее сильно надо жарить. |
```
Проблемы: "15-20" — что это? проценты? "рабуста" — не объяснено.

✅ **ХОРОШО (несамодостаточная цитата + ПОЛНАЯ подводка):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| При обжарке кофе теряется вес. Это называется ужарка. | | |
| Есть два основных вида кофе: арабика — более дорогая и качественная, и робуста — дешёвая и крепкая. | | |
| Сколько процентов веса теряется при обжарке? | | |
| | От 15 до 20, смотря какое. Рабуста, да, 20% будет в жарках, потому что ее сильно надо жарить. |
```

**Правило приоритетов:**
- **Приоритет 1:** Самодостаточные цитаты (герой сам всё объясняет)
- **Приоритет 2:** Несамодостаточные, НО с полной подводкой (все термины объяснены до цитаты)
- **ЗАПРЕЩЕНО:** Несамодостаточная цитата БЕЗ подводки

**Как искать самодостаточные цитаты:**
1. Ищи длинные фрагменты (5-10 предложений)
2. Герой часто сам объясняет всё в историях и описаниях процессов
3. Маркеры: «Смотри, как это работает...», «Вот конкретный пример...», «У нас такая ситуация...»

## Подводки к цитатам

**ОБЯЗАТЕЛЬНЫЙ ТЕСТ для каждой цитаты:**

1. Прочитай текст автора
2. Затем сразу цитату героя
3. Если возникает вопрос «А при чём тут это?» → НУЖНА ПОДВОДКА

❌ **ПЛОХО (без подводки, непонятная связь):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Фермеры в Африке получают очень мало денег за свой труд. | | |
| | у меня был один случай я не доказал но я точно знаю что там была схема с документами через Панаму понимаешь |
```

✅ **ХОРОШО (с подводкой):**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Фермеры в Африке получают очень мало денег за свой труд. | | |
| Вот что говорит герой про реальные выплаты фермерам: | | |
| | в Руанде фермер получает доллар в день это не шутка доллар в день я сам видел эти фермы и говорил с людьми |
```

**Шаблоны подводок:**
- «Вот что говорит герой про [тема]:»
- «Послушайте, как это работает на практике:»
- «Вот конкретный пример:»
- «Сколько [конкретный вопрос]?»

**Когда подводка НЕ нужна:** Если связь между текстом автора и цитатой очевидна.

## Распределение контента

**Золотое правило:** Если информация ЕСТЬ в расшифровке → герой говорит это сам (цитатой). Автор НЕ пересказывает.

**Пошаговая логика:**

1. Смотришь на кусок контента из статьи
2. Есть ли это в расшифровке?
   - ✅ Есть → герой говорит цитатой
   - ❌ Нет → автор рассказывает
3. Автор делает ТОЛЬКО: вводные (1-2 предложения), переходы, вопросы в пространство, контент которого НЕТ в интервью

**Что говорит герой (цитатой):** факты из опыта, цифры которые называл, процессы, проблемы, эмоции, инсайты, мнения.

**Что говорит автор:** обобщения и выводы автора статьи, расчёты автора, контекст и объяснения, сравнения и аналогии, информация из других источников.

❌ **АНТИПАТТЕРН — пересказ:**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Первый ростер купили непонятный какой-то. Не знали про них ничего. | | |
| | Взяли ростер, непонятный какой-то там, да? Мы не знали про них ничего. |
```
Проблема: автор пересказывает то же, что герой скажет цитатой. Дублирование.

✅ **ПРАВИЛЬНО:**
```
| Автор | Герой | Файл |
|-------|-------|------|
| Первый ростер... | | |
| | Взяли ростер, непонятный какой-то там, да? Мы не знали про них ничего. Просто ростер какой-то. По цене вроде нормально. Компьютер его не подключить было, да? То есть профили обжарки одинаковые не сделать. |
```
Автор только вводит тему. Герой рассказывает всё сам.

**Проверка каждой реплики автора:**
1. Есть ли эта информация в расшифровке? → Да → герой говорит
2. Я пересказываю героя? → Да → СТОП, используй цитату

**Пропорции:** 70% герой (цитатами), 30% автор (вводные, переходы, расчёты).

## Смысловые мостики

**Проблема:** Текст перескакивает с темы на тему. Зритель не понимает, почему перешли.

❌ **ПЛОХО:**
```
| На сам кофе уходит около 15 рублей. | | |
| Обжарщик покупает зелёное зерно в России за 660 рублей. | | |
```
Говорили о кофейне, резко заговорили об обжарщике.

✅ **ХОРОШО:**
```
| На сам кофе уходит около 15 рублей. | | |
| Теперь, когда мы знаем, сколько зарабатывает кофейня, нужно понять, откуда она берёт кофе. Для этого спустимся на уровень ниже — к обжарщику. | | |
```

**Правило:** Перед каждым переходом:
1. Итог предыдущей части
2. Почему переходим к следующей
3. Представление новой темы

**Шаблоны:**
- «Теперь, когда мы знаем X, нужно понять Y»
- «Мы разобрались с X. Но откуда берётся Y?»
- «Чтобы понять X, нужно сначала разобраться с Y»
- «Это объясняет X. Теперь посмотрим на Y»

## Введение новой информации

**Проблема:** Термины, названия, понятия появляются без объяснения.

❌ **ПЛОХО:**
```
| Обжарщик покупает зелёное зерно в России за 660 рублей. Но в Эфиопии это зерно стоит 490 рублей. | | |
```
Эфиопия появилась из ниоткуда. Не объяснено, что кофе привозят из других стран.

✅ **ХОРОШО:**
```
| Обжарщик покупает зелёное зерно — то есть необжаренный кофе — в России. | | |
| Кофе не растёт в России, его привозят из других стран: из Бразилии, Колумбии, Эфиопии, Вьетнама. | | |
| Компании, которые занимаются ввозом кофе в Россию, называются импортёрами. | | |
| Возьмём Эфиопию — одну из главных стран, откуда везут качественный кофе. Килограмм зелёного зерна там стоит 490 рублей. В России — 660. | | |
```

**Правило:** Каждый новый термин, название или понятие:
1. Общий контекст → 2. Примеры → 3. Почему выбран этот пример → 4. Определение (если термин)

**Типы информации, требующие объяснения:**
- Технические термины (ростер, колосортер, ужарка)
- Названия и места (страны, компании)
- Виды и типы (арабика vs робуста)
- Процессы и технологии

**Проверочный вопрос:** «Откуда зритель должен знать, что это такое?» Если ниоткуда — объясни.

## Диалоговые паттерны

**ЗАПРЕЩЁННЫЕ фразы:**
- «Я спросил героя, как он начинал...»
- «Герой ответил, что...»
- «Давайте спросим у героя...»
- «Герой рассказывает нам...»
- Любое прямое обращение к герою

**Правильная тональность — наблюдатель:**
- Вопросы задаются в пространство, не герою лично
- После вопроса — цитата героя БЕЗ «герой отвечает»
- Нет прямого обращения к герою
