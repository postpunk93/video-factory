# Анализ материалов для YouTube-сценария

Формат: автор (Слава) исследует бизнес-тему, герой даёт инсайды из интервью. Цепочка создания ценности от сырья до потребителя.

## Когда НЕ использовать
- Нет расшифровки интервью (только статья)
- Видео без героя (монолог автора)
- Формат не про бизнес/деньги

## Шаг 0: Чтение материалов

Прочитать:
- `<project_dir>/raw/article.md` — статья
- `<project_dir>/transcripts/*.transcript.txt` — расшифровки интервью (может быть 1-3 файла)

Если `<project_dir>` не передан — спросить у пользователя.

## Шаг 1: Таблица цифр

⛔ НЕ ПЕРЕХОДИТЬ К СЛЕДУЮЩИМ ШАГАМ, пока таблица не готова.

Выписать ВСЕ цифры из материалов в таблицу:

```
ТАБЛИЦА ЦИФР:

[КАТЕГОРИЯ 1]:
- Значение: XXX [источник: статья / расшифровка, файл Y]
- Значение: YYY [расчёт: формула]
- Значение: ZZZ [НУЖНО УТОЧНИТЬ — в материалах нет]

[КАТЕГОРИЯ 2]:
...
```

**Золотое правило:** НИКОГДА не придумывать цифры.
- Есть в материалах → использовать, указать источник
- Можно рассчитать из имеющихся → пометить [РАСЧЁТ] с формулой
- Нет данных → пометить [НУЖНО УТОЧНИТЬ]

**Правила работы с числами:**
- НЕ округлять без обоснования
- НЕ путать опт и розницу, валовую и чистую прибыль
- НЕ строить цепочку расчётов от неверного числа — проверять каждый шаг
- НЕ придумывать итоговые цифры, которых нет в материалах

## Шаг 2: Фокус исследования

1. **Денежный вопрос** — трансформировать тему в вопрос про деньги
   - Плохо: «Как работает бизнес X»
   - Хорошо: «Почему X стоит так дорого / зарабатывает столько / теряет деньги на Y»

2. **Цепочка создания ценности** — от сырья до потребителя (4-7 участников)
   - Кто участвует? Сколько каждый зарабатывает? Кто получает больше всех?

3. **Место героя** — один из участников цепочки, не центр истории
   - Герой — окно в тему, не тема сама по себе

### Принцип ритма
Каждый смысловой блок (2-4 минуты) должен содержать хотя бы один элемент вовлечения — цитату героя, контраст, вложенную историю или прокси-реакцию автора. Монотонные блоки «автор рассказывает факты 4 минуты подряд» — сигнал, что нужно разбавить.

### Практики «всегда» (применять в каждом сценарии):
- **01 Hook + Promise** — первые 30 секунд: конкретное обещание + stakes
- **02 Open Loops** — 3-5 вопросов в первые 2 минуты, закрывать постепенно
- **05 Interview Format** — 70/30 герой/автор, дословные цитаты, приоритет самодостаточным
- **10 Presenting Numbers** — числа в контексте сравнения, итог после расчётов, не больше 3-4 подряд
- **11 CTA / Closing** — CTA после сильного момента, закрытие на пике, без «подведём итоги»
- **12 Visual Layer** — разметка [B-ROLL], [ГРАФИКА], смена визуала каждые 15-30 секунд
- **13 Pattern Interrupts** — разметка [МУЗЫКА], [ПАУЗА], [INTERRUPT], чередование форматов

### Практики «по ситуации» (выбрать 2-4, если подходят по фактуре):
- **04 Staircasing** — подходит, если в материале есть нарастающий конфликт или эскалация ставок
- **06 Misconception-first** — подходит, если есть распространённое заблуждение, которое можно разрушить фактами
- **07 Curiosity Gap** — подходит, если есть сильный разрыв между ожиданием и реальностью
- **08 In Medias Res** — подходит, если в материале есть яркий, эмоциональный момент для старта
- **14 Hero Arc** — подходит, если в материале герой прошёл трансформацию (точка «до» резко отличается от «после»)
- **15 Contrast** — подходит, если в материале есть пары фактов/цифр, разница между которыми говорит сама за себя
- **16 Nested Narrative** — подходит, если в транскрипте есть яркие мини-истории героя (случай, эпизод) с завязкой и развязкой
- **17 Viewer Proxy** — подходит, если материал содержит контринтуитивные факты или цифры, вызывающие естественное удивление

Для каждой выбранной ситуативной практики — написать:
- Почему подходит для этого материала (конкретная фактура)
- Как именно применить (конкретный план)

## Шаг 4: Структура сценария

### Открывающие вопросы (open loops)
3-5 вопросов, которые открываются в первые 2 минуты и остаются БЕЗ ОТВЕТА до финала.
Формулировки должны быть конкретными, с цифрами или деталями из материала.

### Трёхактная структура

**Акт 1 (завязка, ~20% сценария):**
- Hook + promise + stakes
- Открытие loops
- Контекст: что за тема, почему интересно
- Начало цепочки ценности

**Акт 2 (развитие, ~60% сценария):**
- Детали, расчёты, технология
- Цитаты героя как доказательства
- Постепенное нарастание ставок
- Re-hooks каждые 60-90 секунд
- Закрытие промежуточных loops

**Акт 3 (развязка, ~20% сценария):**
- Ответы на главные вопросы из открытия
- Итоговые цифры (прибыль, окупаемость)
- Закрытие macro-loop
- Финальная эмоция (цитата героя или неожиданный вывод)

Для каждого акта: какие темы, в каком порядке, где open/close loops.

## Шаг 5: Ключевые цитаты

Выбрать 8-12 сильнейших цитат из расшифровок.

Для каждой цитаты:
- Полный текст (copy-paste, без редактирования)
- Источник: файл расшифровки
- Самодостаточная или нет (нужна ли подводка)
- Где в структуре сценария будет использована (акт, тема)

Приоритет: самодостаточные цитаты > несамодостаточные с хорошей подводкой.

Критерии силы цитаты:
- Герой называет конкретные цифры
- Герой описывает живой опыт (история, случай)
- Герой выражает эмоцию или неожиданный инсайт
- Цитата содержит контраст или конфликт
