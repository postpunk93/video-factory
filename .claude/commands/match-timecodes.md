# Match Timecodes — Pass 2: Верификация агентами

Ты оркестрируешь проход 2 пайплайна сопоставления таймкодов. Пользователь даёт путь к проекту (например, `projects/tulips`). Базовая директория — `C:/Users/Alex/Videos/factory`.

## 1. Проверь пререквизиты

- Файл `{project_dir}/script/candidates.json` должен существовать
- В `{project_dir}/transcripts/` должен быть хотя бы один `*.words_compact.txt`

Если чего-то нет — сообщи пользователю и останови выполнение. Подскажи:
- Если нет `candidates.json`: запустить `python _scripts/match_timecodes.py search {project_dir}`
- Если нет `*.words_compact.txt`: запустить `python _scripts/match_timecodes.py compact {project_dir}`

## 2. Прочитай candidates.json и выведи статистику

Прочитай файл `{project_dir}/script/candidates.json`. Он содержит массив `rows`. Каждая строка имеет поле `status`: `single`, `multiple` или `not_found`.

Выведи пользователю сводку:
```
📊 Статистика candidates.json:
  single:    N строк (однозначное совпадение)
  multiple:  N строк (несколько кандидатов — нужен выбор)
  not_found: N строк (не найдено — нужен поиск)
  Итого:     N строк
```

## 3. Подготовь данные для агентов

### Загрузи транскрипты
Прочитай все файлы `{project_dir}/transcripts/*.words_compact.txt`. Формат строки:
```
INDEX    START    END WORD
```
Это фиксированная ширина колонок. INDEX — номер слова, START/END — секунды, WORD — само слово.

### Раздели строки на ~4 чанка
Раздели массив `rows` на примерно 4 равные части. Если строк мало (< 8), используй меньше агентов.

### Для каждой строки подготовь контекст
- **`multiple`**: для каждого кандидата вырежи ±30 слов вокруг `words_start`..`words_end` из соответствующего `words_compact.txt` файла. Это позволит агенту увидеть, полная ли фраза или фальстарт.
- **`not_found`**: передай полный текст `words_compact.txt` файла для соответствующего спикера. Агент будет искать фразу по смыслу.
- **`single`**: вырежи ±10 слов вокруг `words_start`..`words_end` для проверки границ.

## 4. Запусти параллельных агентов

Запусти ~4 Explore-агентов параллельно. Каждому агенту передай такой промпт:

---

Ты верифицируешь таймкоды для сценария русскоязычного YouTube-видео.

Для каждой строки ниже проверь или исправь совпадение таймкода.

### Правила
- **Статус `multiple`**: прочитай контекст вокруг каждого кандидата. Кандидат ПОЛНЫЙ, если содержит всю фразу (не фальстарт и не обрывок). Выбери ПОСЛЕДНИЙ ПОЛНЫЙ кандидат.
- **Статус `not_found`**: ищи фразу в words_compact.txt по смыслу (текст сценария может отличаться от транскрипта). Верни индексы слов и таймкоды.
- **Статус `single`**: проверь, что границы не режут слова. Проверь ±5 слов контекста.

### Важно
- Фальстарты: Слава иногда начинал фразу, останавливался, начинал заново. Выбирай ПОСЛЕДНЮЮ ПОЛНУЮ версию.
- Если текст кандидата обрывается на полуслове — это фальстарт, пропускай его.
- Для реплик героя: убедись, что выбор файла логичен.

### Формат ответа
Верни JSON-массив (и ничего лишнего вокруг него):
```json
[
  {
    "row_idx": 2,
    "chosen": {"file": "filename.mov", "start": 79.88, "end": 87.40, "words_start": 120, "words_end": 138},
    "confidence": "high",
    "note": ""
  }
]
```

- `confidence`: `"high"` — если уверен, `"low"` — если угадывал (например, `not_found` совпал только по 2 словам)
- `note`: пояснение, если что-то необычное

## 5. Собери результаты

После завершения всех агентов:
1. Спарси JSON-массивы из каждого ответа
2. Объедини все результаты в один массив
3. Для каждого результата добавь поля из оригинальной строки candidates.json (`speaker`, `col`, `text`)

## 6. Сохрани verified.json

Сформируй файл `{project_dir}/script/verified.json` в формате:
```json
{
  "rows": [
    {
      "row_idx": 2,
      "speaker": "slava",
      "col": 1,
      "text": "оригинальный текст...",
      "chosen": {"file": "...", "start": 0.0, "end": 0.0, "words_start": 0, "words_end": 0},
      "confidence": "high",
      "note": ""
    }
  ]
}
```

Отсортируй `rows` по `row_idx`.

## 7. Выведи итоговую сводку

```
✅ Верификация завершена. Результат: {project_dir}/script/verified.json

  high confidence:  N строк
  low confidence:   N строк
  не разрешено:     N строк (если есть)

Следующий шаг: python _scripts/match_timecodes.py snap {project_dir}
```

## Обработка ошибок

- Если агент не вернул валидный JSON — попробуй распарсить вручную (может быть обёрнут в ```json ... ```)
- Если строка отсутствует в результатах агентов — отметь её с `confidence: "missing"` и `note: "агент не вернул результат"`
- Если кандидатов 0 и статус `not_found` — агент может вернуть `chosen: null` с пояснением в `note`
