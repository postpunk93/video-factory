# Чеклист ревью сценария

## Как работать

1. Прочитать `script_draft.csv` и `analysis.md` из папки `script/` проекта
2. Пройти по 4 блокам чеклиста ниже
3. Для каждой найденной проблемы записать: описание, номер строки в CSV, исправление
4. Если проблемы есть — исправить CSV и пройти проверку заново
5. Максимум 3 прогона. Если после третьего остались проблемы — сохранить список в `script/review_notes.md`
6. Если после первого прогона всё чисто — готово, не нужно искать проблемы там, где их нет

## Блок 1: Фактчекинг

### 1.1 Числа
Выписать ВСЕ числа из сценария. Для каждого числа найти соответствие в таблице цифр из `analysis.md`.
- Число есть в таблице → ок
- Число помечено [РАСЧЁТ] с формулой → проверить формулу, пересчитать
- Число помечено [НУЖНО УТОЧНИТЬ] → ок, если пометка сохранена в сценарии
- Числа НЕТ в таблице и нет пометки → **ОШИБКА: придуманное число**

### 1.2 Расчёты
Найти все места, где одно число получено из других. Пересчитать каждый шаг.
- Результат совпадает → ок
- Результат не совпадает → **ОШИБКА: неверный расчёт**

### 1.3 Цитаты (выборочная проверка)
Взять 3-4 самые длинные цитаты героя. Для каждой:
1. Найти файл расшифровки, указанный в analysis.md
2. Найти эту цитату в расшифровке (поиск по ключевым словам)
3. Сравнить посимвольно
- Совпадает (включая ошибки, повторы, междометия) → ок
- Отредактирована, сокращена, перефразирована → **ОШИБКА: цитата изменена**

## Блок 2: Драматургия

### 2.1 Hook (первые строки сценария)
Прочитать текст до первой цитаты героя или до ~30 секунд текста.
- Есть конкретное обещание (что зритель узнает)? → ок / **НЕТ PROMISE**
- Есть stakes (почему это важно/удивительно)? → ок / **НЕТ STAKES**
- Начинается с воды, предыстории, «привет, сегодня поговорим»? → **СЛАБЫЙ HOOK**

### 2.2 Open loops
Найти в `analysis.md` список открывающих вопросов (open loops).
- Каждый вопрос открыт в первой трети сценария? → ок / **LOOP НЕ ОТКРЫТ**
- Каждый вопрос закрыт в последней трети? → ок / **LOOP НЕ ЗАКРЫТ**
- Вопросы закрыты слишком рано (в первой половине)? → **LOOP ЗАКРЫТ РАНО**

### 2.3 Re-hooks
Разбить сценарий на блоки по ~60-90 секунд текста (~150-220 слов).
- В каждом блоке есть что-то, что возвращает внимание (новый факт, мини-вопрос, смена масштаба, эмоциональный поворот)? → ок
- Два блока подряд без re-hook? → **ПРОВИС РИТМА**

### 2.4 Выбранные практики
Прочитать в `analysis.md`, какие ситуативные практики выбраны (staircasing, misconception-first, curiosity gap, in medias res).
- Каждая выбранная практика реально применена в сценарии (не просто заявлена)? → ок / **ПРАКТИКА НЕ ПРИМЕНЕНА**

### 2.5 Закрытие
Прочитать последние 5-7 строк сценария.
- Закрытие на пике (сильная цитата, неожиданный вывод, контраст)? → ок
- Есть «подведём итоги», «на этом всё», «спасибо за просмотр»? → **СЛАБОЕ ЗАКРЫТИЕ**
- Macro-loop из hook закрыт? → ок / **MACRO-LOOP НЕ ЗАКРЫТ**

## Блок 3: Доступность

### 3.1 Смысловые мостики
Найти все места, где тема меняется (новый участник цепочки, новый аспект, переход от расчётов к истории).
- Перед переходом есть: итог предыдущего + причина перехода + представление нового? → ок
- Резкий скачок без объяснения? → **НЕТ МОСТИКА**

### 3.2 Термины
Найти все специальные термины, названия, аббревиатуры в сценарии.
- Каждый объяснён ДО первого использования? → ок
- Термин появляется без объяснения? → **ТЕРМИН НЕ ОБЪЯСНЁН**

### 3.3 Итоги расчётов
Найти все блоки с 3+ числами подряд.
- После блока есть итог одним предложением? → ок
- Числа идут потоком без итога? → **НЕТ ИТОГА РАСЧЁТА**

### 3.4 Последовательность информации
Новые понятия, страны, компании — введены в контексте?
- Общий контекст → примеры → почему этот → определение? → ок
- Появляется из ниоткуда? → **ИНФОРМАЦИЯ БЕЗ КОНТЕКСТА**

## Блок 4: Формат

### 4.1 Пропорции
Посчитать строки: сколько строк героя (цитаты), сколько строк автора.
- ~70/30 герой/автор (допустимо 60/40 — 80/20)? → ок
- Автора больше 40%? → **СЛИШКОМ МНОГО АВТОРА**
- Героя меньше 60%? → **СЛИШКОМ МАЛО ГЕРОЯ**

### 4.2 Пересказ
Для каждой реплики автора длиннее 2 предложений: содержит ли она информацию, которая есть в цитатах героя?
- Нет → ок
- Да → **АВТОР ПЕРЕСКАЗЫВАЕТ ГЕРОЯ**

### 4.3 Диалоговые паттерны
Поиск по тексту автора:
- «герой ответил», «герой рассказывает», «я спросил героя», «давайте спросим», прямое обращение к герою
- Найдено → **ДИАЛОГОВЫЙ ПАТТЕРН**

### 4.4 Числа
Все числа в тексте автора написаны словами, как произносятся?
- «два миллиона двести тысяч» → ок
- «2,2 млн», «350к», «14%» → **ЧИСЛО НЕ ПРОПИСАНО**

### 4.5 Монтажная разметка
В сценарии есть:
- `[B-ROLL: ...]` или `[ГРАФИКА: ...]` → хотя бы раз на каждые 2-3 сегмента? → ок / **НЕТ ВИЗУАЛЬНОЙ РАЗМЕТКИ**
- `[МУЗЫКА: ...]` → хотя бы при смене настроения/акта? → ок / **НЕТ МУЗЫКАЛЬНОЙ РАЗМЕТКИ**
- `[ПАУЗА]` → перед ключевыми числами? → ок / **НЕТ ПАУЗ**

### 4.6 CSV-формат
- 4 колонки: Слава, Таймкоды, Герой, Таймкоды? → ок
- Колонки 2 и 4 пустые? → ок
- Строки-заголовки разделов в первой колонке? → ок
